# E0075: RECURSIVE operator never defined

A `RECURSIVE` declaration predeclares an operator's name, arity, and type, but no operator
definition anywhere in the module gives it a body.

## Why it fires

```tla
---- MODULE Example ----
RECURSIVE
    \* @type: Int => Int;
    F(_)
====
```

`F` is declared `RECURSIVE` but never defined with `F(x) == ...`.

## How to fix it

- Add an operator definition matching the predeclared name and arity, anywhere later in the
  module — before or after the embedded algorithm, in any order relative to other declarations.
- Remove the `RECURSIVE` declaration if the operator turns out not to be needed.

## See also

- `E0074` — a name already declared; also covers defining a `RECURSIVE`-predeclared operator
  twice.
- `E0076` — the definition exists, but its own `@type` disagrees with the `RECURSIVE` one.
