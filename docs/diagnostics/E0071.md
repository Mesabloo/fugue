# E0071: macro arity mismatch

A macro call's argument count does not match its declaration's parameter count.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    macro Inc(v) {
        v := v + 1;
    }
    process (P = PID)
        variable x = 0;
    {
    p1: Inc(x, 2);
        goto Done;
    }
}*)
====
```

`Inc` takes one parameter, but is called here with two. The `note:` points back at `Inc`'s own
declaration.

## How to fix it

- Match the call's argument count to the declaration, or add/remove a parameter from the
  declaration if the call is the one that's right.

## See also

- `E0070` — a call to an undeclared macro.
