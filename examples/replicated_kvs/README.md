# replicated_kvs

`ReplicatedKVS.tla`: Distributed PlusCal translation of the classic MPCal
replicated-KV tutorial (archetypes `AReplica` / `Get` / `Put` / `Disconnect` /
`ClockUpdate`). Replicas hold the KV state; each client runs four concurrent
threads (Get-loop, Put-loop, Disconnect, ClockUpdate-loop) sharing one Lamport
clock. `CONSTANT`s: `ReplicaSet`, `ClientSet` (both sets of `Address`). See
the spec's own header comment for the MPCal-to-Distributed-PlusCal porting
notes (global-variable elimination, the stability tie-break fix).

## Layout

- `replicatedkvs/replicatedkvs.go` — generated by `fugue compile`, **not**
  checked in (see `.gitignore`); package form (`-X go-pkg:replicatedkvs`)
  since this example needs two different mains (replica, client).
- `replicatedkvs/constants.go` — supplies `ReplicaSet`/`ClientSet`, fixed to
  three replicas (`r1`,`r2`,`r3`) and two clients (`c1`,`c2`).
- `replica/main.go` — a replica process; `-name` picks which of `r1`/`r2`/`r3`.
- `client/main.go` — a client process (all four threads); `-name` picks `c1`/`c2`.
- `nameserver/main.go` — the rendezvous point processes register/resolve through.
- `run.sh` — builds and starts one name server, three replicas, two clients, wired over TCP.

## Regenerate

`replicatedkvs.go` is not checked in (see `.gitignore`), so generate it first:

```bash
go generate ./examples/replicated_kvs/replicatedkvs
```

Needs `.lake/build/bin/fugue` built (`lake build fugue`).

## Run

```bash
examples/replicated_kvs/run.sh
```

Clients loop their Get/Put/ClockUpdate forever, so this does not exit on its
own — Ctrl-C stops all of them.

Or by hand, in any order (`Lookup` parks until a peer's name appears):

```bash
go run ./examples/replicated_kvs/nameserver -bind 127.0.0.1:9000
go run ./examples/replicated_kvs/replica -name r1 -bind 127.0.0.1:9101 -ns 127.0.0.1:9000
go run ./examples/replicated_kvs/replica -name r2 -bind 127.0.0.1:9102 -ns 127.0.0.1:9000
go run ./examples/replicated_kvs/replica -name r3 -bind 127.0.0.1:9103 -ns 127.0.0.1:9000
go run ./examples/replicated_kvs/client -name c1 -bind 127.0.0.1:9201 -ns 127.0.0.1:9000
go run ./examples/replicated_kvs/client -name c2 -bind 127.0.0.1:9202 -ns 127.0.0.1:9000
```
