# pingpong

`PingPongs.tla`: one `Ping` process, a set of `Pong` processes, bouncing
`"Ping"`/`"Pong"` messages. `Ping` receives on shared mailbox `ping`, replies
on per-`Pong` mailbox `pong[from]`; each `Pong` sends to `ping`, receives on
its own `pong[self]`.

## Layout

- `pingpong/pingpong.go` — generated by `fugue compile`, **not** checked in (see `.gitignore`).
- `ping/main.go` — the `Ping` process, one command.
- `pong/main.go` — a `Pong` process, one command; run once per `Pong`.
- `nameserver/main.go` — the rendezvous point processes register/resolve through.
- `run.sh` — builds and starts one of each above, wired over TCP.

## Regenerate

`pingpong.go` is not checked in (see `.gitignore`), so generate it first:

```bash
go generate ./examples/pingpong/pingpong
```

Needs `.lake/build/bin/fugue` built (`lake build fugue`).

## Run

```bash
examples/pingpong/run.sh
```

Or by hand, in any order (name lookups park until the name appears):

```bash
go run ./examples/pingpong/nameserver 127.0.0.1:9000
go run ./examples/pingpong/ping 127.0.0.1:9000 Pong1 Pong2
go run ./examples/pingpong/pong 127.0.0.1:9000 Pong1
go run ./examples/pingpong/pong 127.0.0.1:9000 Pong2
```
